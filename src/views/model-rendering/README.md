# glTF 模型渲染对照

从首页「渲染技术 → 模型渲染对照」进入，或打开 `/cesium-demo/model-rendering`。

Cesium 和 Three.js 加载同一个 glTF，使用相同的摄影棚线性 HDR 光照函数、主光方向、曝光、色调映射选择和同步视角。不会修改模型的金属度、粗糙度、贴图或着色器。左侧可切回 Cesium 默认光照，观察环境光与 HDR 的贡献。

两个引擎的环境预滤波、BRDF、阴影和地面材质实现不同，这不是逐像素一致性测试。模型默认只投射地面阴影；启用「模型接收阴影」可观察 Cesium 对环境光的压暗。Cesium 专属 AO 默认关闭，避免改变对照条件。背景和地面只用于观察模型。

## 模型与操作

- 内置材质球：上排金属，下排非金属；粗糙度从左到右为 0.07、0.25、0.5、0.85。
- 内置飞机：使用仓库原有 `public/model/Cesium_Air.glb`。
- 本地 GLB：选择一个文件。
- 本地 glTF：同时选择一个 glTF 和配套的 bin、贴图；按文件名匹配依赖，不支持重名依赖。所有文件只在浏览器中读取。
- 两侧都支持拖动旋转、滚轮缩放、Shift 拖动平移；「重置视角」重新框选模型。
- 目前展示静态姿态。Draco、KTX2 材质贴图压缩和动画不在本轮验收范围；加载失败会明确显示错误。

## 运行版本

此前 Vite 将 `cesium` 指向标注为 1.120 的 `src/cesium`，虽然 package.json 安装了 1.132。运行代码与 Workers / Assets 现统一来自已安装的 Cesium 1.132。旧构建文件保留，不再作为运行入口。涉及私有接口的旧特效需要继续单独检查，尤其是反射水面。

## 光照资源

`node scripts/generate-rendering-assets.mjs` 生成：

- `studio.hdr`：Three.js 通过 PMREM 预滤波。
- `studio-specular.ktx2`：Cesium 使用的线性 RGBA32F 立方体贴图，八级 GGX 预滤波 mip。
- `studio-sh.json`：同一光照函数积分得到的漫反射球谐系数，包含余弦卷积及 Cesium 多项式基系数。
- `material-study.glb`：自行生成的材质球几何与 glTF PBR 材质。

生成资源随源码保留，普通开发/构建无需重新生成。这些新资源为本项目原创，未复制商业案例源码。

参考：[Cesium ImageBasedLighting](https://cesium.com/learn/cesiumjs/ref-doc/ImageBasedLighting.html)、[Three.js 色彩管理](https://threejs.org/manual/en/color-management.html)。

对照页使用持续渲染，保证异步 KTX2 环境贴图与阴影加载后立即显示；没有进行帧率验收。

## 本轮结论与效果优先级

1. 先建立模型 PBR 基线：线性 HDR 环境、漫反射球谐、GGX 镜面预滤波、正确曝光与色调映射。材质球和飞机已进行浏览器对照，本地 GLB 加载与两侧同步旋转已验证。
2. 接着处理阴影：Cesium 1.132 的 ShadowMapShader 将 visibility 乘到最终片元 RGB，会一起影响环境光。默认只投影到地面是本对照的取舍，不代表完成了正确的模型自阴影；城市建筑间遮挡需要后续单独解决。
3. 然后做城市场景：使用高质量 glTF 建筑材质、合理粗糙度、昼夜光照预设及接触阴影；先选小街区验收，再扩展规模。
4. 云与天空随后加入：现有体渲染更接近噪声等值面。真实云需要密度积分、透射率、散射与低分辨率重建，可评估开源体积云方案，尚未接入。
5. 最后补粒子：雨、雪、烟雾先做深度遮挡、柔化交界与近远裁剪，再加风场和发光。避免用 Bloom 掩盖材质问题。

## 验证范围

- 新页面专用类型检查、生产构建和 5 项本地模型资源解析测试通过。
- 新生成 GLB / KTX2 / SH 的结构与有限数值检查通过。
- 对照页已在浏览器验证材质球、飞机、本地 GLB、默认/改进光照和同步旋转。
- 全量测试曾报告两个空测试文件和 LayerUtil 无效 CSS 颜色断言失败；用保留的 1.120 入口复查，三个测试文件仍出现相同失败。没有修改这些测试及相关功能。
- 原有示例只做抽查，涉及私有接口的效果没有完成全面兼容性验收。城市、云、粒子尚未实施。

Primitive 示例抽查发现手写 pickColor 与 Cesium 内置拾取属性重复，产生 GLSL 函数重定义；已移除手写属性，保留 id 拾取与高亮逻辑。
