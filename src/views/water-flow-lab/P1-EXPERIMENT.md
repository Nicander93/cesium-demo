# P1 第一轮：流场法线与局部泡沫

状态：可复现的实验实现，不代表 P1 全部画质验收通过。代码建立在 P0 提交 21e1ced 上；不更改水动力计算与数据 JSON 协议，不重写几何管线。

## 技术决策

用相同输入、相机、固定光照和时间对比旧细节水面与可选流场实验。只在现有 Material/Appearance/Primitive 路径内尝试新着色与泡沫来源，没有借助 Vue 实现核心算法，没有引入私有 Cesium API、多 Pass 或外部 ShaderToy 代码。

水面微法线来自固定 ENU 坐标下多尺度 value-noise 的解析梯度。速度矢量只用于两个短周期平流坐标，不旋转世界位置或用局部速度基变换 UV。两相位相差半周期，重置时该相位权重为零。实验周期为 1.9 秒，旧算法保持 4.7 秒；视觉位移限速为 6 m/s，原输入速度与粒子速度保持原值。微法线强度随输入流速变化，无速度输入时该项为零，只保留基础波纹。

重置和混合能限制长期拉伸，但不能证明任意非均匀流场中的纹理坐标都准确沿真实轨迹反向追踪。后续若强梯度工况仍有拉伸，应比较 GPU 流场纹理与反向追踪，不能凭这次四种工况宣称解决所有流场伪影。

新的泡沫源取速度梯度、负散度以及沿流向的水面高程下降，乘以运动和 Froude 激活权重。单位仍是覆盖率/秒，上限 0.42。均匀高速水流不会只因为超临界就自动铺白；干区和缺速度数据不参与生成，也不把干区当作零速度邻居。局部生成后沿用原有限体积示踪输运和指数衰减，范围 0–1，不反写水深或速度。

泡沫的碎片纹理只打散已有覆盖，不凭噪声创造覆盖。高光也可能出现亮色水纹，不能将全部亮色当作泡沫，应结合生成源和覆盖诊断判断。该源项是视觉近似，不是湍流、空气卷吸或障碍物绕流求解。

实验页用 6 秒泡沫寿命，旧算法用 18 秒；因此默认 A/B 比较的是完整视觉配置，不是单一参数消融。第一版出现过宽白带，缩短平流窗口、提高弱梯度阈值并减少泡沫持久时间后收敛；保留旧算法以便继续复查这些选择。

## 可复用调用

```ts
const layer = createCesiumFloodLayer({
  viewer, grid,
  visuals: { surfaceStyle: 'flow', particles: false, foam: true, foamLifetime: 6 },
})
layer.update(externalFrame)
layer.animate(visualSeconds) // 由宿主驱动视觉时钟，与求解时间分离
layer.setVisualOptions({ surfaceStyle: 'baseline' }) // 切换会重置示踪状态
layer.update(externalFrame)
layer.destroy()
```

模块默认 `surfaceStyle: 'baseline'`、`particles: true`，保留其他页面既有外观。`particles` 和 `foam` 是独立控制项；粒子仍受 flow/foam 总开关约束。公开接口没有暴露底层 GPU 对象。实验入口默认选新算法，并关闭粒子，方便观察水面本身。

## 实际验收（2026-10-14）

- 79 项水面/洪水测试通过，包括局部源、顺流落差方向、无速度、干区、输入不变及有界输运。
- 专项 TypeScript 检查和生产构建通过；仍有既有的大 chunk 提示。
- Chromium 155.0.8059.40，Cesium 1.132，1440 × 900，ANGLE (NVIDIA, NVIDIA GeForce RTX 5070 (0x00002F04) Direct3D11 vs_5_0 ps_5_0, D3D11)。
- 四种工况均保存 basic/current/flow 截图，并分别保存旧/新生成源和覆盖诊断。默认均关闭粒子，固定 15 秒，近景 heading=0.18、pitch=-0.42、range=80；两算法共用光照 ENU direction=(-0.25,-0.9,-0.55)、intensity=1.5。
- GPU 测试检查实际 Material/Appearance 组装源中的 5 个 uniform 无重复，并用实际帧验证编译。没有 GLSL、浏览器异常或实验页外网请求错误。
- 相位边界 0.95、1.9、9.5、15.2 秒分别取前后 0.001 秒的 GPU 截图。固定近景 ROI 为 x=360、y=180、980 × 650；平均 RGB 差 0.1334–0.1345（0–255），各样本高于 25 的变化像素比例为 0。阈值检查防止大面积跳闪，不等同于整个动画全时段的视觉验收。
- 关闭粒子后，15 与 15.25 秒画面平均 RGB 差为 10.1847，确认纹理/法线自身在动。
- 无速度降级、冻结像素一致、三次 Viewer 重建、实际 Vue 路由卸载返回通过；连续相机拖动视频包含 16.56 秒实际动画。

## 保留问题和后续顺序

这轮比旧算法更容易观察局部水纹，但天空近似反射、简单体积水色和光照仍影响真实感；尚无完整 Mind3D/ShaderToy 效果对标结论。四种输入为解析合成场，缺少真实水域配准和动态洪水水位验证。

尚未验证实际跌水/坝体、场景反射、桥梁/3D Tiles 遮挡、任意强剪切场、无速度动画切换的全部路径，以及多效果兼容。矩形试验格网的岸线几何仍粗糙。局部示踪尚无新增空间扩散；速度场快速变化时目前每帧重建网格和离散更新的成本仍未测量。

下一步先用既有溃坝场景和更近的流场视角检查真实交互与跌水局部源；完成动态水位与流向验收后，再做 GPU 状态纹理与 Primitive 重建的性能对照。此阶段仍不确定插件宿主、Monorepo 或发布结构。
