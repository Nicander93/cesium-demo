# 滨水城市环境实验

入口：`/cesium-demo/city-rendering`，首页「渲染技术 → 滨水城市环境实验」。

## 场景与来源

- 建筑：Kenney City Kit (Commercial) 2.1，19 种 GLB 资源，在实验场景中放置 24 栋。
- 车辆：Kenney Car Kit，6 种车辆，最多 40 辆，三条闭合车道，双向运行、转角圆弧与车轮转动。它是视觉车流，不包含红绿灯、避让和交通仿真。
- 城市布局、三座桥、道路、河岸与绿化：本项目生成的 PBR glTF 底座，Three 对照底座可用 `pnpm generate:city-ground` 重建；Cesium 地理场地可用 `pnpm generate:city-ground --site-only` 重建为 `riverside-site.glb`，不包含周边大平板。
- Kenney 模型为 CC0，原许可证放在 `public/city-rendering/kenney/{city,cars}/LICENSE.txt`。来源与下载归档哈希记录在 `sources.json`。
- 水面：复用 `src/water` 的局部反射水面，不需要外部地图或 ion token。
- 体积云、大气与云影：MIT 的 [cesium-clouds-atmosphere](https://github.com/yuwoniu03/cesium-clouds-atmosphere)，上游基于 [three-geospatial](https://github.com/takram-design-engineering/three-geospatial)。完整许可与本地改动说明位于 `src/vendor/cesium-clouds-atmosphere`。LUT 与云纹理完全本地加载。

本场景是可控的风格化滨水街区，没有使用真实城市测绘数据或倾斜摄影模型。

## 效果与控制

1. 晴天、夕照和雨天预设控制日照时间、阳光、云量和雨量；曝光可以独立调整。时间按街区所在的中国时区显示，固定为夏季日照参考。
2. 体积云包含密度积分和 Beer Shadow Map；体积光强度调节云影下的大气散射。在「河岸看云」视角查看天空，夕照更容易观察逆光效果。
3. 「体积云与大气」关闭时，回到 Cesium 基础天空与模型环境光，可用于定位复杂管线问题。
4. 雨使用实际 Cesium 粒子，受风偏移，在水面、桥梁、地面或建筑包围盒顶部结束。建筑碰撞为保守范围，未做逐三角形碰撞。
5. 道路湿润降低粗糙度并加深路面；局部积水为东岸车道上的独立反射水面，使用「街道积水」视角观察。它不是降雨蓄水、水深演化或排水模拟，也没有完成雨滴撞击涟漪。
6. 画质控制主画布分辨率、建筑阴影、水面反射与云步数。云当前为 0.75 分辨率；框架使用归一化 UV 重建射线，确保缩放后的云正确遮挡。

## 关键接入修正

- 模型使用中性摄影棚 IBL 作为稳定的明暗基线，避免没有环境光时模型背光面完全发黑。
- 云、大气和模型先在线性 HDR 域合成，最后统一执行 PBR Neutral 色调映射与显示 gamma。Cesium 自带色调映射默认位于自定义后处理之前，`hdr.ts` 仅对本实例执行阶段做临时跳过，并在 finally 中恢复；页面退出恢复原执行方法。没有修改全局 prototype。
- 云的射线与深度使用归一化屏幕坐标，避免半分辨率 `gl_FragCoord` 对不上主视口。
- 移除了上游针对 globe depth plane 的低空深度忽略逻辑。该规则会将低层城市建筑误认为假深度，导致云覆盖楼体。
- 日照时间跳变或重新开启下雨时重置粒子时钟，避免一次大时间步生成过多粒子。

## 检查与限制

```sh
pnpm typecheck:city
pnpm validate:city-assets
pnpm exec vitest run src/views/city-rendering src/water
pnpm build
```

自动浏览器检查暂时被审批服务 429 限流阻止。用户截图确认了最初的偏暗与云遮挡问题；已经据此修正，实际画面需要继续确认。编译通过不代表所有 GPU 路径已验收。

云管线使用私有 WebGL 与 Cesium 状态，接入基于 Cesium 1.132；更换版本需要专项检查。积水、湿润和粒子是效果原型。尚未验收性能目标、移动设备和全部天气组合。

回归检查现包括 22 项城市与水面测试，包含 HDR 异常状态恢复、真实云着色器的 Cesium 内建函数注入，以及雨开关/时间重置。着色器组装检查仍不能替代 GPU 编译与实际画面验收。已修正截图报出的坐标入口函数注入错误，并移除线性 HDR 输入上的重复 gamma 解码。高级天空发生运行错误时会关闭该管线并尝试恢复基础场景。

## 与仓库已有体渲染的关系

已对照 `src/views/volume-rendering/{index.vue,CustomPrimitive.ts,Texture3D.ts}`。旧示例在 128³ Perlin 体素中做包围盒相交和光线步进，超过 threshold 就以不透明表面退出；因此它展示的是噪声等值面，没有沿整条射线累积透射率与太阳散射。城市云继续使用已有接入的密度积分管线，并借用旧示例的体积范围调试方式：面板提供云底高度、云层厚度与云量，直接更新三维云层的采样范围。旧示例没有被改写。

最近截图对应的修正：默认关闭模型自阴影，建筑与车辆投射阴影、底座接收阴影，避免模型自阴影条纹；实验自阴影仍可单独开启。调整默认视角与云层范围，扩展河流和周边地面，避免总览仅出现顶部云带和悬空街区。雨粒子撞到地面时标记为已过期，不再将寿命置零；真实 Cesium Particle 在零时间步下的回归检查确认 normalizedAge 不产生 NaN，覆盖反射渲染同时间步再次更新的情形。上述画面修正仍待实际浏览器确认。

## Three.js 城市对照与最新验收

新增 `/city-three`，城市页顶部「Three.js 城市对照」可进入。两页共享 GLB、模型布局、车流路径、摄影棚 HDR 和日照时间；Three 页提供曝光、太阳、自阴影、车流、动态倒影与波速调节。Three 页采用简化天空，两页的预设相机坐标一致，相机拖动未实时同步。它用于查看模型渲染差异，两套天空与水面不构成逐像素基准。

已修复大气 LUT 上传方向：Cesium Texture 默认 flipY=true，而上游 Three DataTexture 查找表按未翻转行序保存。2D 透射率/辐照度表错误翻转会使云补光读取错误高度；现在所有 LUT 明确使用 flipY=false，加入回归检查。天空曝光原先声明但未参与输出，现仅在天空辐射度分支生效，不再依靠整体曝光补偿。

云保留密度积分与太阳散射，暂停未验收的历史帧重建；无历史重建时使用固定噪声切片。原生 GL 拷贝使用独立 VAO，并恢复程序、纹理、帧缓冲与渲染状态。减轻近处云的重复遮光，收敛密度。河面增加与 Three 页同源的程序法线，按河流实际长宽采样，反射基值降到 0.04，扭曲减轻，连续更新波纹。共享 src/water 未改动。

2026-10-12 浏览器检查已恢复：实际加载了 Cesium 和 Three 页各 65/65 模型，检查了晴天、雨天街道、局部积水与相机拖动；未捕获渲染错误。修正后雨云不再接近黑色，晴天品红云边消失，河面有动态扰动。自动浏览器的帧率不能代表用户桌面上的稳定性能；持续拖动的流畅度与所有 GPU/天气组合仍需实机观察。远景为基础地面，场景美术仍是 Kenney 风格化测试街区。

倒影在相机移动期间提高到最多 60 次/秒，相机停止后恢复画质对应的 15/30/60 次更新上限，避免静止时额外 GPU 开销。移动事件在页面销毁时解除。

### 云、水面与阴影复查（2026-10-12 晚）

- CloudShadowPass 和 ShadowResolvePass 使用完整的离屏状态保护：5 个纹理单元的 2D/3D 纹理与 sampler、独立 VAO、program、buffer、读写 framebuffer、viewport、clearColor 和写入掩码均在 finally 恢复。此前只保护了 blit，遗漏了两个每帧云阴影 pass。
- jitterStrength 现在实际参与 shader；无云历史累积时固定采样起点，避免屏幕噪声随拖动切换密度采样。BSM resolve 使用当前帧，云自身光照不再依赖随相机变化的 BSM 级联。
- 太阳次级步长不再除以迭代数；此前只采样几十米，不能遮蔽千米厚的云层。主步长上限明确限制，上层云覆盖率下降，默认厚度 1400m，增加“进入云层”视角。
- 河面使用 24 个交叉波段和三组移动采样，远距离法线衰减；倒影从 LDR sRGB 转入主画面 HDR，轻度模糊，不再增加原来的人造白色反光底。共享岸边泡沫实验仍在其他任务中演进，城市河面显式关闭它。
- Cesium shadowMap.darkness 从 0.7 改为 0.25；该参数是最低可见度。城市自己的 primitive receiver bias 校准为 normalOffsetScale=0.5、depthBias=0.00015，默认打开建筑互相接收阴影。Three 阴影贴图提高到 4096，减小浮空偏移。
- 真实浏览器已检查云层近景、晴天河岸、街道模型互相遮挡、一次云层视角拖动，未见控制台渲染错误。截图只能证明结果帧，不能证明整段拖动每一帧都没有闪烁；自动检查窗口帧率不作为用户机器性能结论。

### 天空与地平线接缝复查（2026-10-13）

用户反馈拖动时云闪烁，天空像背景图，地平线有独立蓝色条带。此次修改统一云、天空和空中透视的主相机射线；它不再取决于渲染几何最后使用的视锥或离屏视口。深度纹理使用原始 R 通道和 log-depth 重建入口，移除误用的 RGBA 打包深度解码。天空分流按实际深度判定，不再依赖亮度阈值。

城市现在显示无影像的连续椭球地面，接住有限测试底板以外的视线；原先关闭 globe 后露出的蓝色清屏条带被消除。云层交点覆盖云下、云内、云上以及背向云层的视线，不保留未初始化范围。主采样覆盖完整有效区间，不在云层前部耗尽步数。云阴影在同一个 preRender 回调中按参数更新、渲染、resolve、发布的顺序执行，云关闭时停止这些 pass。城市云影贴图降为 512，主画布均衡画质限制为 1 倍分辨率，精细画质上限 1.25 倍，减少高 DPI 开销。

类型检查、生产构建和 31 项城市/水面回归检查通过。新增检查覆盖相机旋转响应、视口缩放及几何视锥变化时的射线一致性、当前帧云影发布顺序。浏览器自动访问被网址安全策略拒绝，本轮未完成 GPU 实际画面与连续拖动验收；不能据此宣称闪烁完全解决或帧率达标。

### 影像地球与复用边界（2026-10-13）

Cesium 城市页已接入 ArcGIS World Imagery 影像地球，保留 640m 范围内的示意街区和人工河道，去除遮挡底图的两块大面积绿色平板。影像按 Cesium provider 显示来源署名，加载失败在页面提示；可通过 `VITE_CITY_IMAGERY_URL` 替换为有权使用的 ArcGIS MapServer 服务。接入接口见 [Cesium 官方文档](https://cesium.com/learn/cesiumjs/ref-doc/ArcGisMapServerImageryProvider.html)。该远程演示服务依赖网络与服务可用性，模型、IBL 与云资源仍为本地资源。

`createCityScene(container, report, placement?)` 接收经度、纬度、椭球高程，默认 119.0317°E、33.5921°N、0m。建筑、道路、雨粒子使用同一 ENU 局部坐标；河面和积水高程随场地高度一起调整。影像不是 DEM，当前仍是椭球上的平整示意场地，不代表真实地表测绘结果。若接入真实地形，需要先采样地形高程，再确定统一场地高程、开挖河槽或整平场地，否则直接增加 terrainProvider 可能使道路和水面穿地。

| 模块       | 当前实现                                                  | 复用边界                                                                        |
| ---------- | --------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 地理场景   | Cesium Viewer、影像地球、ENU 模型与车流                   | 城市可通过 placement 整体换位置；街区布局和资产仍固定                           |
| 模型与光照 | glTF PBR、摄影棚 IBL、太阳光、阴影、统一 HDR 色调映射     | 光照接入仍写在 city scene，尚未抽成公共控制器                                   |
| 云与大气   | 三维密度光线步进、大气 LUT、云阴影与散射                  | viewer 实例级 apply/destroy；含 Cesium 私有接口适配，尚未完成连续拖动稳定性验收 |

Three.js 页是独立的同模型对照，Cesium 页没有叠加一个 Three renderer。复用时应把 Viewer、影像、地形与模型布局归场景层，把光照、云、水、雨归效果层，统一管理 apply/destroy、画质与资源释放。目前是实验模块组合，还不是经过不同地形和模型验收的通用高质量渲染包。

### 地球缩放与模型清晰度（2026-10-13）

取消原先 8km 的最大缩放距离，允许缩放到 50000km，并提供「地球总览」快捷视角。云采样上限现在约束云内路径长度，避免太空相机尚未抵达云层就耗尽距离预算；远距淡出扣除云层上方的径向距离，避免俯视时把云完全淡出。侧向长路径仍使用有限采样预算，这不是全球气象云数据。

城市启用独立云缓冲：低分辨率 raymarch 只输出云的预乘 radiance 和 opacity，随后使用 full-resolution merge 合成原始场景。Cesium PostProcessStageComposite 的 inputPreviousStageTexture=false 保证建筑、水面和影像不经过 0.75 倍云缓冲缩放。云细节 LOD 由硬切换改为渐变，代表云深度按消光贡献加权。TAA 仍关闭，不能凭源代码检查宣称拖动无闪烁。

地表云影通过整个场景颜色衰减，会同时压暗环境光与自发光，不能视为真正的直接光云影。因此城市默认关闭此实验项，保留云自身遮光和大气散射；开启时限制后处理云影强度。地表大气透视独立提供开关，可与模型基础 PBR/IBL 作对照。目前仍未接入 DEM，用户观察到的变化不能归因于新地形材质。
