### 关键代码解析

#### 1. 网格系统初始化

```glsl
float resolution = 10. * exp2(-3.*iMouse.x/iResolution.x);
vec2 uv = fragCoord.xy / iResolution.y * resolution;
vec2 p0 = floor(uv);
```

- 📐 **动态分辨率**：通过鼠标位置控制波纹密度（鼠标越右→分辨率越低→波纹越大）
- 🔳 **网格划分**：将屏幕划分为网格单元，每个单元可能产生水滴

#### 2. 波纹生成（核心循环）

```glsl
for (int j = -MAX_RADIUS; j <= MAX_RADIUS; ++j) {
    for (int i = -MAX_RADIUS; i <= MAX_RADIUS; ++i) {
        vec2 pi = p0 + vec2(i, j);
        // ...
        float t = fract(0.3*iTime + hash12(hsh)); // 时间偏移
        vec2 v = p - uv;                         // 方向向量
        float d = length(v) - (float(MAX_RADIUS) + 1.)*t; // 扩散半径
```

- 🔁 **双层循环**：遍历当前像素周围(2×MAX_RADIUS+1)²的网格
- ⏱️ **时间控制**：每个波纹有独立的时间线（`hash12`产生随机偏移）
- 🌊 **扩散模拟**：`d = 距离 - 随时间增大的半径` 实现波纹扩散效果

#### 3. 波纹形状函数（关键数学）

```glsl
float p = sin(31.*d) * 
          smoothstep(-0.6, -0.3, d) * 
          smoothstep(0., -0.3, d);
```

- 📈 **波形控制**：
  - `sin(31*d)`：高频正弦波产生波纹细节
  - `smoothstep(-0.6,-0.3,d)`：控制波纹**外边缘**渐变
  - `smoothstep(0,-0.3,d)`：控制波纹**内边缘**渐变
- 🌀 组合效果：形成环形波纹带（内外边缘之间）

#### 4. 法线计算（水流效果核心）

```glsl
// 数值微分求梯度
float h = 1e-3;
float p1 = /* d-h 处值 */;
float p2 = /* d+h 处值 */;
vec2 gradient = (p2 - p1) / (2.0 * h); 

// 累积法线贡献
circles += 0.5 * normalize(v) * gradient * (1. - t) * (1. - t);
```

- 🧮 **数值微分**：通过微小偏移计算坡度（模拟水面高度变化）
- ⬆️ **法线合成**：
  - `normalize(v)`：径向向量（波纹中心→当前像素）
  - `gradient`：波纹坡度强度
  - `(1-t)²`：随时间衰减

#### 5. 渲染效果合成

```glsl
vec3 n = vec3(circles, sqrt(1. - dot(circles, circles))); // 3D法线
vec3 color = 
    texture(iChannel0, uv/resolution - intensity*n.xy).rgb + // 折射
    5.*pow(clamp(dot(n, lightDir), 0., 1.), 6.);           // 高光
```

- 💧 **折射效果**：用法线偏移纹理坐标（模拟光线弯曲）
- 💡 **高光特效**：基于法线和光源方向（`lightDir = (1,0.7,0.5)`）计算
- ⚖️ **物理模拟**：`sqrt(1 - dot(circles,circles))` 确保法线长度归一

### 参数调整指南
