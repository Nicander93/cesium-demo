# 山海景观实验页

独立的 Cesium 场景展示页，用于比较真实山地水库与程序化滨海布景，并调节环境、水面和镜头。页面路由为 `/cesium-demo/landscape-showcase`；本地调试时可用 `?scene=coast` 或 `?scene=mountain` 选择初始场景。

## 场景内容

### 峡谷水境：Mauvoisin

- 使用瑞士 swisstopo 公开 DEM 地形服务与 SWISSIMAGE 影像服务，地形和影像会按视点逐步细化，依赖网络连接。
- 湖面边界使用项目内的 `public/landscape-showcase/mauvoisin.geojson` 水域轮廓；展示水位通过 DEM 样点与岸边地形对齐，用于画面演示，不代表实时或测量水位。
- 湖面反射真实山地场景，水面位置来自公开水域轮廓。

### 滨海漫游：合成展示场景

- 海岸线、海滩、道路和城市街区是程序化演示布景，不对应真实地理位置或实测海岸。
- 办公楼由本页的程序化 GLB 生成器创建；车辆复用本地 Kenney 模型，树木以批量几何绘制。
- 该布景用于展示海岸城市构图和水面效果，不是倾斜摄影、真实城市模型或工程数据。

参考截图所展示的地形、城市资产和整体画面并非本页使用的同一套数据。本页实现相近的场景构成与观感方向，不承诺与截图一比一复刻。

## 共享渲染方式

- 环境光与模型照明走项目共享的 Environment 控制器及其 HDRI/IBL 配置；两种场景共用同一环境与水面模块。
- 水面通过 `WaterSurface` 绘制水平水面、平面场景反射和近岸 mask。滨海场景将 mask 范围限制在近岸区域，以维持岸线细节；远处海面几何延伸到视野外。
- 云层不使用体积光线步进。天空观感由共享环境、天空背景和场景照明控制。

## 页面控制

- 天气：晴天、夕照。
- 画面：曝光、水面颜色。
- 水面：波浪强度、主波尺度、粗糙度、场景倒影开关与强度、岸线白沫开关与宽度。
- 渲染档位：均衡、流畅。
- 机位：主视角、贴岸近看、空间总览；可开启缓慢巡游。拖动或滚轮输入会停止巡游。
- 两种场景的选项分别保存到浏览器本地存储。当前场景、天气、机位和调节项写入 URL，可通过复制场景链接分享。

## 性能边界

- 主画面按容器尺寸自动缩放，绘制像素数上限约为 1920 × 1080；低于该尺寸时使用浏览器推荐分辨率。
- 水面反射最长边上限：均衡档 1024 像素，流畅档 640 像素。相机静止时反射更新上限为 15 FPS；相机移动时优先刷新反射。
- 近岸 mask 使用局部范围，避免为远海范围分配同等岸线精度。
- 城市模型异步加载并限制并发；地形、影像及水面反射的实际表现仍受设备 GPU、浏览器和网络服务状态影响。

## 验证

在 `D:\code\cesium-demo` 仓库根目录运行：

```powershell
pnpm typecheck:landscape
pnpm exec vitest run src/views/landscape-showcase
```

浏览器集成与交互性能检查：

```powershell
pnpm smoke:landscape
```

Smoke 脚本需要可访问的开发服务、Playwright/Chromium 与公开山地数据服务；它会驱动浏览器并采集交互帧时间。可设置 `SHOWCASE_BASE_URL` 指向当前开发服务，或设置 `SHOWCASE_SCREENSHOTS=1` 额外保存场景截图。结果受本机 GPU、浏览器版本和网络细化状态影响；烟测通过不等于不同设备上的视觉效果或帧率保证。

- 真实山体贡献通过反射帧缓冲的开/关地形对照验证；辅助反射前后的主视图地形选择保持一致。调低反射质量后仍保留山体倒影。

## 资产与材质更新（2026-10-30）

- 办公楼分为砖楼、玻璃办公楼、退台高层，增加外挑窗框、裙房、屋顶设备。临海一排使用较低的砖楼，默认镜头移到滨海道路附近。
- 52 栋楼复用 12 份预生成 GLB，约 1.53 MiB，避免每次进页现场生成整片街区。车辆继续使用原有 Kenney 资产。
- 123 株羽状棕榈使用一个约 0.80 MiB 的 `EXT_mesh_gpu_instancing` GLB，保留 6 种原型。存储几何共 10,440 个三角面，按实例绘制仍为 214,020 个三角面；实例化主要减少 CPU 合并、上传和临时缓冲，不能免去实例的顶点计算。
- 地面增加纵向道路、路口标线、楼前铺装和临海道路公园。地表 shader 使用连续的 ENU 米制坐标，并按像素足迹衰减细节，保持当前环境与反射通道。
- 新资产的作者调色板按 sRGB 编写，导出 GLB 时转换为线性材质因子，修正棕榈发白和立面偏亮。

修改生成器、布局或材质后，在 Node.js 24 环境重新生成静态资产：

```powershell
pnpm generate:showcase-offices
pnpm generate:showcase-palms
pnpm typecheck:landscape
pnpm exec vitest run src/views/landscape-showcase src/views/environment-lab/reservoir-data.spec.ts src/water/spec
```

资源一致性测试会将发布 GLB 与当前生成器输出比较，防止页面继续使用旧的几何或颜色。
